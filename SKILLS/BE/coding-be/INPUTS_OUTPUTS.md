# Coding Backend - Inputs and Outputs

## Allowed Inputs
- `AGENTS.md`
- `SKILLS/BE/shared/*`
- `AI-Share-Documents/Analysis/**`
- `BE/<Project name>/src/**`
- Target backend project configuration needed to understand build and module wiring

## Allowed Outputs
Write only to:
- `BE/<Project name>/src/**`
- `AI-Share-Documents/BE/04-coding-be/coding-plan.md`
- `AI-Share-Documents/BE/04-coding-be/coding-change-log.md`
- `AI-Share-Documents/BE/04-coding-be/coding-self-check.md`

## Precondition
System Design must mark backend work as in scope. If backend is out of scope, write `Status: NOT_IN_SCOPE` to `AI-Share-Documents/BE/04-coding-be/coding-self-check.md` and stop.
When backend is in scope, `sd-data-design.md` must exist and be implementation-usable for backend work before coding may start.

## Execution Rule
`coding-plan.md` must be created before any production code changes start.
