# Team Lead - Checklist

## Fail-Fast Preflight
- [ ] Read `ba-open-questions.md` before any other BA artifact.
- [ ] Confirm no blocking `Status: OPEN` item remains.
- [ ] If blocked, write only a blocking `tl-self-check.md` and stop.

## Planning Work
- [ ] Validate BA self-check.
- [ ] Read accepted BA artifacts after preflight passes.
- [ ] Decide implementation scope: `BE_ONLY`, `FE_ONLY`, `FULL_STACK`, or `ANALYSIS_ONLY`.
- [ ] Identify backend tasks only when backend is in scope.
- [ ] Identify frontend tasks only when frontend is in scope.
- [ ] Identify BE-to-FE document sharing tasks only when backend handoff is required for frontend.
- [ ] Identify testing tasks only for in-scope surfaces.
- [ ] Identify archive/reset task.
- [ ] Carry assumptions into risk and handoff artifacts.
- [ ] Complete all Team Lead artifacts.
- [ ] Publish completed planning artifacts to `AI-Share-Documents/Analysis/02-team-lead/`.
