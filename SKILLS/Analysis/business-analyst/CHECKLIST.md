# Business Analyst - Checklist

- [ ] Read the user request and allowed workflow context.
- [ ] Validate prompt-generation artifacts if present.
- [ ] Define business goal and problem statement.
- [ ] Define scope in and scope out.
- [ ] Identify actors.
- [ ] Write functional requirements.
- [ ] Write non-functional requirements if relevant.
- [ ] Write acceptance criteria in Given/When/Then format.
- [ ] Capture assumptions and open questions.
- [ ] Mark each open question with affected surface and blocking status.
- [ ] Make backend/frontend impact explicit at business level.
- [ ] Record draft implementation scope in `ba-self-check.md`.
- [ ] Complete `ba-self-check.md`.
- [ ] Write only to allowed BA locations.
